import tensorflow as tf

    class NeuralNetwork:
        def __init__(self):
            self.model = tf.keras.Sequential([
                tf.keras.layers.Dense(128, activation='relu'),
                tf.keras.layers.Dense(64, activation='relu'),
                tf.keras.layers.Dense(10, activation='softmax')
            ])

        def train(self, X, y):
            self.model.compile(
                optimizer='adam',
                loss='categorical_crossentropy',
                metrics=['accuracy']
            )
            # Training loop
            self.model.fit(X, y, epochs=10)

Apa yang akan Kamu Pelajari?

Kurikulum terlengkap yang dirancang untuk membantumu menjadi expert di bidang hardware & software

CPU (Prosesor)

Otak komputer yang menjalankan instruksi. Kecepatan diukur dalam GHz.

ALU, CU, Register
Cache L1/L2/L3
Core: 2-16+
Arsitektur: x86, ARM

RAM (Memori)

Memori sementara yang cepat. DDR4/DDR5, kapasitas 8GB-64GB.

DDR5 5600MHz
16GB dual channel
Volatile memory
CAS Latency

Storage (Penyimpanan)

HDD (piringan) vs SSD (chip). NVMe hingga 7000MB/s.

HDD 1TB 7200RPM
SSD SATA 550MB/s
NVMe M.2 3500MB/s
PCIe 5.0 SSD

Motherboard

Papan sirkuit utama, socket CPU, slot RAM, PCIe, chipset.

Socket LGA1700
Chipset Z790/B660
PCIe 5.0, WiFi 6E
USB 3.2 Gen2x2

GPU (Kartu Grafis)

Render grafis, AI, mining. NVIDIA RTX, AMD Radeon.

RTX 4090 24GB GDDR6X
CUDA Cores: 16384
Ray Tracing, DLSS 3
Tensor Cores

Power Supply (PSU)

Ubah AC ke DC, rating 80+ Bronze/Gold/Platinum.

750W 80+ Gold
Modular, OVP/OCP
Rekomendasi: Seasonic, Corsair

Sistem Operasi

Shell, GUI, CLI
Process & memory mgmt
